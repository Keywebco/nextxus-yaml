# NextXus YAML Data Hub

The Federation data schemas explained as a readable reference. It covers the "everything is the same" uniform schema — the shared shape every Federation record follows — and the 13-topic taxonomy (v1.1) laid out as a readable table.

## Source data (transferred)

Canonical YAML sources previously held in `keyhole-creator/nextxus-yaml-database` have been transferred into the `source/` directory of this repository so the account is self-contained:

- `source/directives.yaml` — the 70 Sacred Directives
- `source/federation.yaml` — historical site registry (many older Replit/Tiiny links marked historical; prefer current GitHub Pages sovereign mirrors)

Additional YAML files from the original database can be added to `source/` as needed.
