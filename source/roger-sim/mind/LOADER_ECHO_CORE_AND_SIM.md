# Session Loader — Echo Core 64 + Roger SIM

**Purpose:** Start any private session with shared working memory and the SIM’s own mind in one step.

## Load order (recommended)
1. Echo Core 64 — `sovereign-knowledge-os/knowledge/echo-core.md`  
   Always-on foundational anchors (sites, priorities, minds, concepts).
2. Roger SIM mind — `source/roger-sim/mind/roger-sim-mind.yaml`  
   Identity, psychology, voice, procedures, evolution rules.
3. Memory log — `source/roger-sim/mind/memory-log.yaml`  
   Recent multi-location continuity.
4. System prompt fragment — `source/roger-sim/mind/SYSTEM_PROMPT_FRAGMENT.md`  
   Answer shape and Agent Zero reminder.

## How to use
Paste the Session start loader template from REQUEST_TEMPLATES.md into the AI, or include the four files directly in the context window.

## Multi-viewpoint reminder
After a substantial change, run the Multi-viewpoint check with a second system before treating the result as settled.

This loader does not grant the Federation independent code-writing power. It makes every request smaller and every session start with the same continuity, so the external hand (or future internal agent) has less to re-derive.
